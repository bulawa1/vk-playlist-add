# 🎵 VK Playlist Saver

Скрипт на Node.js, который автоматически добавляет все треки из любого публичного плейлиста ВКонтакте в вашу музыку.

## ✨ Возможности

- Добавляет до 1000+ треков за один запуск
- При капче автоматически ждёт 3 минуты и продолжает — никакого ручного вмешательства
- Обратный отсчёт в терминале во время паузы
- Если прервался — можно продолжить с любого трека (`START_FROM`)
- Не требует сторонних зависимостей — только Node.js

## 📋 Требования

- [Node.js](https://nodejs.org) версии 18 или выше

## 🚀 Установка и запуск

### 1. Скачай скрипт

```bash
git clone https://github.com/ВАШ_НИКНЕЙМ/vk-playlist-saver.git
cd vk-playlist-saver
```

Или просто скачай файл `vk_add_playlist.js` напрямую (кнопка **Raw** → Ctrl+S).

### 2. Получи токен VK

Открой в браузере (должен быть залогинен в VK):

```
https://oauth.vk.com/authorize?client_id=6287487&scope=audio,offline&redirect_uri=https://oauth.vk.com/blank.html&display=page&response_type=token
```

После редиректа скопируй из адресной строки значение между `access_token=` и `&expires_in`.

> ⚠️ Токен действует 24 часа. Никому не передавай его — он даёт доступ к твоему аккаунту.

### 3. Найди ID плейлиста

Открой плейлист в VK. В адресной строке будет что-то вроде:
```
https://vk.com/audios123456?z=audio_playlist123456_7
```
Здесь: `owner_id = 123456`, `playlist_id = 7`

### 4. Настрой скрипт

Открой `vk_add_playlist.js` в любом текстовом редакторе и заполни:

```js
const TOKEN       = 'твой_токен_сюда';
const OWNER_ID    = 123456789;   // ID владельца плейлиста
const PLAYLIST_ID = 1;           // ID плейлиста
```

### 5. Запусти

```bash
node vk_add_playlist.js
```

Пример вывода:

## ⏸️ Продолжить с места остановки

Если скрипт прервался — открой файл и измени `START_FROM`:

```js
const START_FROM = 150; // начать с трека #150
```

## ⚙️ Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| `TOKEN` | — | Токен VK (обязательно) |
| `OWNER_ID` | — | ID владельца плейлиста |
| `PLAYLIST_ID` | — | ID плейлиста |
| `ACCESS_HASH` | `''` | Хэш доступа (для приватных плейлистов) |
| `START_FROM` | `1` | С какого трека начать |
| `DELAY_MS` | `2000` | Задержка между запросами (мс) |
| `CAPTCHA_WAIT_MS` | `180000` | Пауза при капче (3 минуты) |

## ❓ Частые вопросы

**Почему нужен специальный токен, а не обычный?**  
VK закрыл Audio API для сторонних приложений. Токен от `client_id=6287487` (VK Music) даёт доступ к методам `audio.*`.

**Что делает скрипт при капче?**  
Автоматически ждёт 3 минуты с обратным отсчётом, затем повторяет тот же трек. Никакого ручного вмешательства не нужно — можно оставить на ночь.

**Сколько времени займёт 1000 треков?**  
~33 минуты при задержке 2 сек. Если VK пришлёт капчу пару раз — добавится ещё 6-10 минут.

**Трек не добавился — что делать?**  
Скрипт выводит список в конце. Обычно это значит, что трек удалён или недоступен в твоём регионе.

**Токен протух (24 часа прошло)?**  
Получи новый по той же ссылке, вставь в скрипт и продолжи с нужного трека через `START_FROM`.

## ⚠️ Дисклеймер

Скрипт использует неофициальный доступ к Audio API ВКонтакте. Используй на свой страх и риск.
